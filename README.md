# ORBIT - Object Recovery Based on Integrated Tracking

ORBIT automatically matches lost and found item reports using a C++ core engine (hash tables, tries, linked lists, priority queues) combined with Gemini API semantic text matching for descriptions. Node.js/Express backend, MongoDB storage, React dashboard frontend.

## Project Structure
- `engine/` - C++ matching engine (DSA core + Gemini API integration)
- `backend/` - Node.js/Express REST API
- `frontend/` - React dashboard
